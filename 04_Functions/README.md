# Module 04 - Functions

## 📖 Overview

Functions are reusable blocks of code that perform a specific task.

They help reduce repeated code, improve readability, and make programs easier to maintain and test.

---

## 🎯 Learning Objectives

After completing this module, I will be able to:

- Understand what functions are
- Define and call functions
- Use parameters and arguments
- Return values from functions
- Use default arguments
- Understand local and global scope
- Use functions with collections
- Build reusable functions for data analysis
